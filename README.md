# Semantic Parser NLP  
**Fast and Efficient Annotation for Semantic Parsing**

---

## 📂 Data Variants

Each dataset version reflects a different method of data collection:

- **Nat**: Original examples from GeoQuery/Scholar
- **Lang**: Utterances paraphrased by crowd workers
- **Overnight**: Automatically generated training data
- **GrAnno**: Unlabeled inputs labeled through canonical paraphrase selection by crowd workers

All logical forms use lambda DCS, and testing is based on original test splits.

---

## 🧠 Model Training

- Built on a CopyNet-based architecture using AllenNLP
- Trains using specified domains, data versions, and embeddings (GloVe or ELMo)
- Evaluated using denotation accuracy; logs saved in the `/logs` directory

---

## 🧬 Grammar-Based Generation

- Canonical utterances and logical forms can be generated by traversing grammar trees
- Used primarily for GrAnno data creation and reproducibility

---

## 📁 Grammar Outputs

Pre-generated outputs matching tree depth 6 are included in `grammar_output.zip`.
